# CORE.SINGL — Персональный интерфейс оператора

Полностью статический сайт (HTML/CSS/JS), без бэкенда, без API-ключей.
Работает на GitHub Pages «из коробки».

## Как это работает

1. **Интро** (10-15 сек, можно пропустить): система "находит" оператора,
   сканирует соцсети/проекты/показатели, голо-фигура и данные сходятся
   в одну точку — профиль подтверждён — данные разлетаются вниз.
2. **Главная страница**: одна длинная прокручиваемая HUD-лента. Вверху —
   светящееся ядро (декоративное), ниже — все разделы по порядку:
   Профиль → Показатели → Навыки → Когнитивный профиль → Инженерия →
   Проекты → Связи. Каждый раздел подсвечивается своим цветом.
3. **Терминал** — кнопка вверху открывает командную строку с командами
   `profile`, `skills`, `performance`, `projects`, `network`, `status`.

## Структура файлов

```
index.html      — вся разметка (интро + разделы главной страницы)
style.css       — вся визуальная система
data.js         — ВСЕ редактируемые данные сайта (см. ниже)
core.js         — фон: частицы, чертёж силуэта, ядро, голо-фигура (Canvas 2D)
intro.js        — сценарий интро (стадии, терминал, окна, рассеивание данных)
modules.js      — заполнение разделов данными из data.js
terminal.js     — интерактивный терминал
main.js         — точка входа
assets/         — сюда можно положить свои изображения/файлы (опционально)
```

## Как редактировать контент

**99% правок делаются в одном файле: `data.js`.** Открой его, поменяй
значения, сохрани — сайт обновится сам.

### Добавить новый проект

В массив `projects`:
```js
{
  id: "my-project",
  name: "MY PROJECT",
  status: "В РАЗРАБОТКЕ",
  statusColor: "cyan", // cyan | amber | red | purple | green
  desc: "Описание проекта.",
  tech: ["HTML", "JS"],
  linkLabel: "ОТКРЫТЬ ПРОЕКТ",
  link: "https://..."
}
```

### Добавить новую соцсеть

В массив `network`:
```js
{ id: "x", name: "X", handle: "@handle", link: "https://x.com/handle", color: "cyan" }
```

## Фоновая музыка

В правом верхнем углу есть кнопка **♪ МУЗЫКА** — включает/выключает
фоновую дорожку. Файл трека в комплект не входит (авторские права).

Чтобы добавить свою музыку — положи файл по одному из путей (можно
использовать любое из двух имён, ищутся оба):
- `assets/paranoid.mp3`
- `assets/theme.mp3`

Используй только трек, на который у тебя есть права (свой, куплен,
royalty-free, или лицензия позволяет использование на сайте). Без файла
кнопка просто ничего не проигрывает — сайт не ломается.

Музыка запускается одновременно с интро — на самом первом экране
сайта есть кнопка **«ЗАПУСТИТЬ ПОИСК ОПЕРАТОРА»**: нажатие на неё и
включает музыку, и стартует саму последовательность интро (это
единственный экран, требующий действия от пользователя — дальше всё
идёт само). Так сделано потому, что браузеры не разрешают запускать
звук без явного жеста пользователя. После этого — обычный тумблер
♪ МУЗЫКА в углу экрана, можно выключить и снова включить в любой
момент. Играет на умеренной громкости (35%), зациклена, пока не
выключишь кнопкой или не уйдёшь со страницы. Пока музыка играет,
центральное ядро на главном экране слегка "дышит" в такт басам
(аудио-реактивность через Web Audio API).

## Дополнительные эффекты

- **Аудио-реактивное ядро** — пульсирует и меняет свечение в такт басам
  играющей музыки.
- **Полоса сканирования** — тонкая вертикальная шкала справа экрана
  (на главной странице), показывает процент прокрутки, в стиле
  "SCAN 43%". Скрыта на очень узких экранах, чтобы не мешать.
- **Параллакс фона** — фоновый чертёж силуэта смещается медленнее
  контента при скролле, создавая ощущение глубины.
- **Частицы за пальцем** — лёгкий голографический след частиц при
  движении пальца/курсора по экрану (полностью некликабельный слой,
  не мешает взаимодействию).
- **DEV MODE (пасхалка)** — долгое нажатие (0.6 сек) на центральное
  ядро на главном экране показывает на 1.5 секунды декоративный
  "режим отладки" (HUD-сетка, координаты, RENDER_60FPS). Также
  доступно скрытой командой `devmode` в системном терминале.

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub.
2. Залей все файлы из этой папки в корень репозитория.
3. **Settings → Pages → Source → Deploy from a branch → `main` / `/ (root)`**
4. Через 1-2 минуты сайт будет доступен по адресу:
   `https://<твой-юзернейм>.github.io/<репозиторий>/`

## Технические детали

- Без сборки, без npm, без фреймворков.
- Фон, ядро и голо-фигура — чистый Canvas 2D (не WebGL/Three.js) —
  специально для плавной работы на обычных Android-телефонах.
- Фоновый чертёж (`blueprint-canvas`) рисует абстрактный технический
  силуэт синими линиями поверх всей страницы — как инженерная схема.
- Каждый раздел имеет свой акцентный цвет (cyan/red/amber/purple/green)
  и HUD-рамки по углам — раскрашенная голографика вместо монохрома.
- Разделы плавно проявляются при прокрутке (IntersectionObserver).
- Шрифты: Chakra Petch + Space Mono, через Google Fonts CDN.
- Интро можно пропустить кнопкой в правом верхнем углу.
